v0.5.0
------
- Added native Windows FolderPicker (IFileDialog/FOS_PICKFOLDERS on STA thread).
- Added live read-only Status and Progress UI controls (no controller focus).
- Added DynamicButton with client-defined enabled state.
- Added RU/EN localized variants and reflection SDK wrappers for all four APIs.
- Restored controller focus through native Selectable.Select() rather than EventSystem.current.
- Preserved all v0.4.3 public API signatures and existing three-column UI.
- The r1 candidate was compiled and field-tested in game on 2026-10-25.
- Runtime known-good SHA256: 38DD49305050CE877067ECB8F05F87257BD7EB5C16E601C12726BA35BEA097A2.
- No game save, client configuration ownership, or gameplay logic changes.

v0.4.3
------
- Added the host-owned middle MODS column: ALL MODS plus every registered mod.
- Selecting a mod filters the existing right settings renderer by modId; ALL MODS preserves the complete registry view.
- Existing client DLLs populate the new selector automatically through existing RegisterMod calls; no rebuild is required.
- Added independent scrolling for the middle mod selector and right settings list.
- Added Header registry entries plus AddHeader/AddHeaderLocalized public API methods.
- Header entries are non-interactive, controller navigation skips them, and they participate in normal order sorting.
- Added SDK SupportsHeaders() and graceful old-host fallback behavior.
- Added automatic RU/EN localization for ALL MODS and localized Header content through the existing host language mechanism.
- Long selector names wrap instead of being truncated with ellipsis; selector typography and spacing were polished for readability.
- Long right-column setting names use TMP word wrapping instead of ellipsis.
- Wrapped setting names grow only their own row height; one-line settings retain the native compact height.
- Slider/Toggle/Choice/Button value/control geometry on the right remains unchanged horizontally.
- Header titles use a smaller bold uppercase hierarchy, native separator and subsection spacing.
- Preserved v0.3.1 native/MODS panel isolation and v0.2.1 settings auto-scroll.
- Preserved all existing public method signatures and backward compatibility with previously built client DLLs.
- No game-save, client-config ownership or gameplay changes.

v0.3.1
------
- Fixed a regression where MODS content could remain active together with a native Options panel and become visible below GENERAL when scrolling.
- Added a runtime panel-isolation invariant: any active native Options panel forces Options - Mods inactive.
- Preserved v0.3.0 RU/EN localization and v0.2.1 selection auto-scroll.
- No public API changes.
- No SDK changes.
- UI Scaler is unchanged.
